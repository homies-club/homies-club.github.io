# Carpeta SRC (Código Fuente)

Esta es la carpeta principal de tu página web. Aquí es donde sucede toda la magia. A continuación, una explicación rápida de lo que hace cada archivo importante aquí:

- **data.js**: ¡El archivo más importante para ti! Aquí están todos los datos de tu carta (hamburguesas, alitas, bebidas, precios e imágenes). Si quieres cambiar un precio o foto de un plato, hazlo aquí.
- **App.jsx**: Este es el armazón de tu página. Se encarga de apilar todas las secciones (como si fueran legos) para formar la página completa (primero pone el Navbar, luego el Hero, el Menu, etc.).
- **index.css**: Aquí están los estilos globales. Los colores principales (como el naranja brillante y el fondo oscuro) y el tipo de letra de toda la web se configuran en este archivo.
- **main.jsx**: Este es un archivo técnico que arranca tu página web. Por lo general, nunca necesitarás tocar este archivo.

Recuerda: Cualquier cambio que guardes en estos archivos se reflejará automáticamente en tu web de pruebas.
